# Browser-Use Demo Project

This is a demonstration project showcasing the use of the `browser-use` library for UI automation.

## Setup

1.  Install the required dependencies: `pip install -e .`
2.  Install optional development dependencies: `pip install -e '.[dev]'`

## Structure

- `src/agents/`: Contains agent logic for specific tasks.
- `src/utils/`: Contains helper functions.
- `config/`: Contains configuration files.
- `tests/`: Contains unit and integration tests.
- `data/`: Used for input/output data during automation runs.
